# UI 与交互设计

## 1. 信息架构

```text
BI 报表
├── 报表列表
│   ├── 新建/复制/启停/删除
│   └── 进入报表设计器
├── 数据源管理（管理员）
├── 报表设计器
│   ├── 基础信息
│   ├── 查询控件
│   ├── 上方组件区域
│   ├── 下方表格区域与层级
│   ├── 参数映射
│   ├── 权限
│   ├── 版本
│   └── 预览
└── 报表查看页 /report/view/{uuid}
```

第一版设计器面向 1440px 及以上桌面浏览器；最低支持 1280px。查看页适配常见桌面宽度，不承诺手机布局。

## 2. 报表列表

### 2.1 页面结构

```text
┌──────────────────────────────────────────────────────────────────┐
│ 报表管理                                           [新建报表]    │
├──────────────────────────────────────────────────────────────────┤
│ 名称/UUID [____________] 状态 [全部▼] 创建人 [____] [查询][重置] │
├──────────────────────────────────────────────────────────────────┤
│ 名称       UUID       状态  组件数  当前版本  更新时间      操作 │
│ 销售分析   f2f...     启用    4        8      08-25 10:00  ...  │
└──────────────────────────────────────────────────────────────────┘
```

操作包括设计、打开、复制、启停和删除。UUID 提供复制按钮；“打开”在新标签进入运行页。无对应权限的操作不显示。

### 2.2 新建向导

只要求名称、默认数据源和默认存储过程。创建成功后进入设计器，系统自动启用下方表格区域并生成：

- UUID；
- 一个 `regionType=TABLE`、`componentKey=main_table` 的表格对象；
- 一个 `ROOT` 路由；
- 从存储过程读取但尚待确认的参数映射草稿。

草稿只存在于前端编辑状态；未完成参数映射前报表不能启用。

## 3. 报表设计器

### 3.1 总体布局

```text
┌────────────────────────────────────────────────────────────────────┐
│ ← 报表列表  销售经营分析  v8  已保存       [预览][保存 Ctrl+S]    │
├──────────────┬───────────────────────────────────┬─────────────────┤
│ 页面导航     │ 仪表盘画布                         │ 属性面板        │
│ ·基础信息    │ ┌───────────┐ ┌───────────────┐   │ 当前组件/层级  │
│ ·查询控件    │ │ 指标卡     │ │ 趋势图         │   │ 字段/图表/钻取 │
│ ·组件区域    │ └───────────┘ └───────────────┘   │                 │
│ ·表格区域    │ ┌─────────────────────────────┐   │                 │
│ ·参数映射    │ │ 下方主表格（固定全宽）       │   │                 │
│ ·权限/版本   │ └─────────────────────────────┘   │                 │
└──────────────┴───────────────────────────────────┴─────────────────┘
```

设计器维护一个完整 `ReportDesignConfig` 编辑副本。切换页面不会自动保存；离开存在未保存修改时必须提示。

### 3.2 保存行为

- 保存前执行本地结构校验，再调用后端完整校验和原子保存。
- 保存按钮显示当前 `expectedVersion`；版本冲突时保留本地内容并提供“重新加载”和“复制 JSON 备份”操作，不自动覆盖。
- 保存成功更新版本号和“已保存”状态，配置立即对新运行请求生效。
- 自动保存第一版不启用，避免频繁产生版本。

## 4. 基础信息

字段包括名称、描述、状态、默认数据源、默认存储过程、最大行数和超时秒数。选择过程后立即读取参数签名；签名不支持时显示原因并禁止保存启用状态。

最大行数默认 50,000，可在 1～200,000 之间设置；超时默认 60 秒，可在 1～600 秒之间设置。页面说明前端全量分页模式的风险。

## 5. 查询控件配置

### 5.1 控件列表

控件支持拖动排序。每行显示标签、类型、必填、选项来源和目标对象数量。

编辑抽屉包含：

- 控件键、标签、类型、默认值、必填和类型特有校验；
- 静态选项表格或 SQL 选项配置；
- 目标对象多选，可选择上方组件和下方表格；
- 对每个目标对象展示相关存储过程参数映射状态。

### 5.2 SQL 选项编辑

- 选择数据源后输入只读 SQL。
- “验证并预览”最多显示前 20 项和是否截断。
- 必须返回 `value`、`label`；页面显示其实际数据库类型。
- 页面明确提示第一版不支持引用其他控件；只允许服务端系统参数 `:currentUserId`。
- 校验失败只显示安全化错误和追踪号，不显示数据库内部细节。

## 6. 两区域设计器

报表设计页固定按以下顺序组织：

```text
查询控件区
组件区域（可关闭，包含 1..N 个图表/指标卡）
表格区域（可关闭，最多 1 个动态表格）
```

至少启用一个数据区域。组件区域和表格区域分别保存、查询和显示数据，不要求字段相关。

### 6.1 上方组件区域栅格

- 固定 12 列，上方组件按整数栅格拖动和缩放。
- 默认组件尺寸：指标卡 `3×4`、图表 `6×8`。
- 最小尺寸由组件类型限制，禁止负坐标、重叠和超出 12 列。
- 拖动结束后压缩空行，但不改变同一行内用户指定顺序。

### 6.2 上方组件操作

工具栏提供新增柱状图、折线图和指标卡。选中组件后可以重命名、复制、删除、刷新预览和打开属性面板。组件类型是配置属性，不编码进 `componentKey` 或传入存储过程。

复制组件生成新的 ID 和 `componentKey`，复制 ROOT 字段和图表配置；参数映射复制为待验证状态。

删除组件前列出受影响控件目标和参数映射，确认后在本地编辑副本中删除，最终随整个配置保存。

### 6.3 下方表格区域

- 使用启用开关控制是否显示，启用后自动创建 `main_table`，报表内最多一个 TABLE 对象。
- 表格固定显示在组件区域下方并占满可用宽度，不参与栅格拖拽。
- 表格可以拥有多个下钻层级，每层字段结构可完全不同，但展示类型始终为 TABLE。
- 关闭表格区域前必须确认将删除其路由、字段、钻取边、控件目标和参数映射。

## 7. 区域对象与层级配置

### 7.1 上方组件配置

每个上方组件只有一个 `ROOT` 数据状态，配置柱状图、折线图或指标卡的字段映射。第一版不在上方组件配置钻取边；上方组件点击只执行图表自身提示和选择交互，不触发下方表格查询。

### 7.2 表格层级树

```text
表格区域 main_table
├── ROOT
│   └── 门店明细 STORE_DETAIL
│       └── 客户订单 ORDER_DETAIL
```

- 根层固定为 `ROOT`，不可删除。
- 新增层级时填写路由编码和名称，展示类型固定为 TABLE。
- 层级树根据钻取边展示，保存时禁止环路和不可达层级。
- 同一源路由的一列只能配置一条钻取边。

### 7.3 字段表格

| 属性 | 说明 |
|---|---|
| 物理字段 | 必须与结果集别名一致 |
| 显示名称 | 用户看到的列名/系列名 |
| 类型 | 字符、数字、日期、日期时间、布尔、JSON |
| 角色 | 维度、度量、值、载荷、样式 |
| 排序 | 当前层显示顺序 |
| 显示 | 载荷和样式字段必须隐藏 |
| 固定 | 无、左、右，仅表格有效 |
| 宽度/对齐 | 表格显示属性 |
| 格式 | 日期或数字格式 |
| 样式字段 | 引用同层隐藏 STYLE 字段 |

支持行拖动排序。字段被图表、样式或钻取引用时，删除按钮进入禁用态并显示引用位置。

### 7.4 上方图表映射

- 柱状图/折线图：选择一个维度字段作为 X 轴，选择一个或多个度量字段作为系列。
- 可配置图例、标签、左右数值轴和堆叠；不允许输入任意 JavaScript formatter。
- 指标卡：选择一个值字段、数字格式、标题和可选样式字段。
- 图表配置引用的字段必须是当前层可见字段，且类型满足维度/度量要求。

### 7.5 表格钻取边

配置项：

1. 触发字段 `triggerField`；
2. 目标层级 `targetRouteCode`；
3. 传给 `p_drill_field` 的 `routeValue`；
4. 隐藏 JSON 载荷字段 `payloadField`。

预览区显示一次模拟点击后生成的请求，但不允许开发者直接编辑 `p_user_id`。

## 8. 参数映射

页面按“报表默认过程”“上方组件覆盖过程”和“下方表格覆盖过程”分组：

```text
参数名          类型          来源          映射值
p_user_id       varchar(64)   系统参数      当前用户 ID
p_region_key    varchar(16)   区域参数      COMPONENT/TABLE
p_component_key varchar(64)   组件参数      component_key
p_date_start    date          查询控件      ctrl_date.start
p_date_end      date          查询控件      ctrl_date.end
p_store_ids     json          查询控件      ctrl_store.value
p_drill_field   varchar(64)   钻取参数      field
p_drill_value   json          钻取参数      value
```

- 元数据同步后新增、删除或变化参数高亮显示。
- 系统参数和钻取参数提供固定候选，不允许自由输入路径。
- 控件候选只显示作用于当前组件且类型可兼容的控件子值。
- 所有 IN 参数完成映射且签名一致后，分组状态才为“有效”。

## 9. 权限和版本

### 9.1 权限

权限页通过可搜索的多选下拉分别选择角色和用户，选项同时展示中文名称与角色编码/用户账号。页面显示“满足任意一项即可访问”，并提供以某个用户身份检查授权结果的只读诊断功能；诊断不模拟业务数据权限。

### 9.2 版本

版本列表显示版本号、操作类型、修改人、时间、摘要和来源版本。差异页按基础信息、控件、组件、层级、字段、参数和 ACL 分类显示。

回滚需要输入摘要并二次确认。回滚成功后生成新版本并立即生效。

## 10. 报表运行页

### 10.1 页面结构

```text
┌──────────────────────────────────────────────────────────────────┐
│ 销售经营分析                              [导出报表] [打印]     │
├──────────────────────────────────────────────────────────────────┤
│ 日期 [2026-08-01 ~ 2026-08-25] 门店 [全部▼] [查询] [重置]      │
├───────────────────────┬──────────────────────────────────────────┤
│ 销售额指标卡           │ 销售趋势                                 │
├───────────────────────┴──────────────────────────────────────────┤
│ 主表格     ROOT / 门店明细 / 客户订单       [刷新] [导出]       │
│ 动态表格                                                         │
└──────────────────────────────────────────────────────────────────┘
```

### 10.2 加载与刷新

- 首次进入加载运行配置和选项；必填控件有有效默认值时分别查询上方组件和下方表格，否则等待用户填写。
- 点击查询只刷新控件绑定的上方组件或表格；未被变更控件影响的对象保持原状态。
- 查询期间组件显示骨架或遮罩，不清空旧数据；成功后原子替换。
- 上方组件独立刷新使用当前控件且始终查询 ROOT；表格独立刷新使用当前控件和当前钻取状态。
- 控件变更后再次执行全局查询时，受影响的表格回到 `ROOT`，避免旧钻取上下文与新筛选冲突；上方组件正常刷新。

### 10.3 下钻

- 表格可钻列显示链接色和指针；上方图表数据点第一版不触发表格下钻。
- 点击后先校验载荷字段为 JSON 对象，再发起下一层查询。
- 成功后追加面包屑；失败时停留当前层并展示组件内错误。
- 点击面包屑上级使用历史请求重新查询，成功后截断其后的历史。
- 只有下方表格维护钻取历史。

### 10.4 表格分页排序

- 首次结果加载后在浏览器内维护完整行数组。
- 排序作用于完整已加载数组，再切分分页；支持单列升序、降序和清除排序。
- 默认每页 50 条，可选 20、50、100、200。
- `truncated=true` 时在组件顶部持续显示“结果已截断，排序和导出仅针对已返回数据”。
- 使用虚拟渲染，禁止同时创建 50,000 个 DOM 行节点。

## 11. 导出与打印交互

- 单组件导出文件名：`{报表名}-{组件名}-{yyyyMMddHHmmss}.xlsx`。
- 整报表导出文件名：`{报表名}-{yyyyMMddHHmmss}.xlsx`；上方每个组件和下方表格分别生成工作表，指标卡汇总到概览页。
- 导出期间显示进度并禁止重复触发；用户可取消前端工作簿生成。
- 截断数据必须二次确认，取消后不生成文件。
- 打印前切换专用 CSS，隐藏控件按钮和操作栏，保持当前筛选、上方组件数据、表格层级和当前表格分页。
- 打印结束或取消后恢复原布局，不重新查询。

## 12. 错误与空状态

| 状态 | 展示 |
|---|---|
| 无数据 | 组件内显示“暂无数据”，保留标题和刷新操作 |
| 配置已更新 | 顶部提示并自动重新加载运行配置，未保存用户输入尽量保留 |
| 查询超时 | 组件内显示超时和追踪号，可重试 |
| 数据源不可用 | 组件内显示暂不可用，不展示连接细节 |
| 字段不匹配 | 显示“报表配置与数据结果不一致”，仅开发者可展开缺失字段名 |
| 无权限 | 跳转 403 页面，不加载任何运行配置 |
